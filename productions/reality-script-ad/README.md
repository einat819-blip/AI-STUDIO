## הקול

`audio/vo/danit_take.mp3` הוא הקובץ שהגיע מ ElevenLabs: הקלטה אחת של כל הטקסט. הוא תומלל עם Whisper של ivrit-ai עם זמן לכל מילה (`audio/vo/words.json`), נחתך למשפטים ב `edit/vo_split.py`, וכל משפט יושב במקום שלו בעריכה. כשמשפט ארוך או קצר יותר מהמתוכנן, כל מה שאחריו זז איתו.

ההקלטה נעשתה לפי התסריט הקודם, ולכן:

* **נכנס:** ״אלגנטית? התחלת טוב.״, ״אריה? איזה מקורי.״, ״תמחק, תמחק!״, ״יהודה רואה את זה.״, ״טוב, מספיק, תן לי לכתוב את התסריט.״, ״יש לכם רעיון לסרט?״ ו״AI NATI STUDIOS״ שנכנס עם הלוגו.
* **לא נכנס, שייך לסיום הקודם:** ״עכשיו אנחנו מדברים.״, ״אצלנו המציאות לא קובעת את התסריט. אתם כן.״, ״בואו נהפוך אותו למציאות.״
* **חסר בהקלטה:** ״מה לעשות? אני קשה עם ספקים.״ ו״תשאירו את העבודה הקשה לי.״. בינתיים הם מופיעים ככתוביות בלבד, באותו תזמון. לא יוצר להם קול חלופי.

## שפה גרפית

* **פרומפטים והתראה:** אותו רכיב זכוכית כהה. בפרומפט יש תווית זהב וסמן מהבהב, ובהתראה אייקון אדום, תווית ״התראה״ ו״עכשיו״. ההתראה מופיעה בבת אחת, כמו הודעת מערכת, ולא מוקלדת.
* **כתוביות דיאלוג:** לבן עם קונטור כהה. ההדגשות בטורקיז ובזהב, ואדום רק ל״תמחק, תמחק!״. בסצנה החדשה מודגשות ״התסריט.״, ״ספקים.״, ״רעיון לסרט?״, ״תשאירו״ ו״לי.״. כל מילה קופצת בדיוק כשהיא נאמרת.
* **שקופית הסיום:** סגול עמוק, טורקיז, ורוד חשמלי ולבן. טיפוגרפיה ב Rubik ו Heebo, הלוגו המקורי והאייקונים בצבעי הרשתות.

## הלוגו

הלוגו חולץ מהסרטון של הסצנה הממותגת הקודמת (`source/v5.mp4`) בעזרת `edit/logo_extract.py`. ברזולוציה של המקור הוא קצת רך. לגרסה הסופית כדאי להחליף אותו בקובץ הלוגו המקורי: PNG עם רקע שקוף, ברוחב 1500 פיקסלים לפחות. שמים אותו במקום `.work/icons/logo.png` ומריצים מחדש.

## מדריך הקלטה לשני המשפטים החסרים

באותו קול ובאותן הגדרות של הקובץ הקיים (Danit, ‏stability 50, ‏similarity 75), קובץ נפרד לכל משפט, בלי מוזיקה.

| קובץ | טקסט | מקום בעריכה | אורך יעד | הערה |
|---|---|---|---|---|
| `d6` | מה לעשות? ... אני קשה עם ספקים. | 23.25 | ״מה לעשות?״ 0.5, הפסקה של חצי שנייה, הפאנץ׳ 1.0 | הפאנץ׳ מתחיל ב 24.15, רגע אחרי שהמוזיקה נעצרת. אדיש לגמרי, משיכת כתפיים בקול |
| `d7b` | תשאירו את העבודה הקשה לי. | 27.7 | 1.6 | חם ובטוח, עם חיוך. הצורות נכנסות ב 30.1 |

כשהם יגיעו הם נכנסים ל `vo_split.py`, והעריכה מתיישרת אליהם: הכתוביות, עצירת המוזיקה לפני הפאנץ׳ וכניסת הצורות.

## בנייה מחדש

```bash
cd edit
pip install fonttools brotli numpy pillow "opencv-python-headless<5"
python3 prepare.py        # פונטים, אייקונים, לוגו, קליפים, מוזיקה, וחיתוך הקול למשפטים. מדפיס אילו אפקטים חסרים
python3 audio.py          # מיקס ומאסטר ל 14 LUFS בערך. הקול נכנס מ .work/vo והמוזיקה מונמכת מתחתיו
python3 video.py ../output/out.mp4
```

כל הזמנים נמצאים ב `edit/timeline.py`. זמני המילים מגיעים מ `.work/vo/lines.json`, ובלעדיו הקובץ חוזר לתזמון הזמני.
