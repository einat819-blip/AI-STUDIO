## שפה גרפית

* **פרומפטים והתראה:** אותו רכיב זכוכית כהה. בפרומפט יש תווית זהב וסמן מהבהב, ובהתראה אייקון אדום, תווית ״התראה״ ו״עכשיו״. ההתראה מופיעה בבת אחת, כמו הודעת מערכת, ולא מוקלדת.
* **כתוביות דיאלוג:** לבן עם קונטור כהה. ההדגשות בטורקיז ובזהב, ואדום רק ל״תמחק, תמחק!״. בסצנה החדשה מודגשות ״התסריט.״, ״ספקים.״, ״רעיון לסרט?״, ״תשאירו״ ו״לי.״.
* **שקופית הסיום:** סגול עמוק, טורקיז, ורוד חשמלי ולבן. טיפוגרפיה ב Rubik ו Heebo, הלוגו המקורי והאייקונים בצבעי הרשתות.

## בנייה מחדש

```bash
cd edit
pip install fonttools brotli numpy pillow "opencv-python-headless<5"
python3 prepare.py        # פונטים, אייקונים, לוגו, קישור לקליפים, המרת מוזיקה. מדפיס אילו אפקטים חסרים
python3 audio.py          # מיקס ומאסטר ל 14 LUFS בערך. קבצי קול ב .work/vo נכנסים אוטומטית
python3 video.py ../output/out.mp4
```

כל הזמנים נמצאים ב `edit/timeline.py`, כולל זמן לכל מילה בכתוביות.

## מקורות

* מוזיקה: ElevenLabs Music v2.5 דרך Higgsfield, ‏`audio/music`. בסיום משמש `m6_brandA`, עם תיבה אחת שחוזרת כדי שהשיא יחזיק עד המכה האחרונה.
* אפקטים: Epidemic Sound דרך Higgsfield. הקבצים לא נשמרים בריפו, המזהים נמצאים ב `edit/prepare.py`. לפני קידום ממומן כדאי לוודא שהרישיון מכסה פרסום מסחרי.
* אייקונים: simple-icons ברישיון CC0, בצבעי המותג של כל רשת. הלוגואים עצמם הם סימני מסחר של הרשתות.
* פונטים: Heebo ו Rubik ברישיון OFL.
