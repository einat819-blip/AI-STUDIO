## החלטות עריכה ששונו מהבריף

* **דיאלוג 4 עבר לסוף סצנה 3.** קליפ 4 נפתח כשהיד כבר באמצע הנקישה, ואין בו זמן למשפט לפניה. המשפט נאמר כשהיא לבד על הספה אחרי המחיקה, וב ״התסריט״ חותכים לנקישה. זה גם מחזק את הפאנץ׳: היא אומרת ״תן לי לכתוב״ ובחיתוך הבא המחשב כבר אצלה.
* **ההנעה לפעולה כתובה כפרומפט.** החלונית האחרונה נקראת ״התסריט שלכם״, והסמן נשאר מהבהב ומחכה לצופה. זו סגירת מעגל ל ״אתם כן״.
* **שם הסטודיו לא מופיע שוב בטקסט.** הלוגו כבר נמצא בראש הפריים, ושורת הפייסבוק מציגה AI NATI STUDIOS.
* **כיתוב לקריינות הסיום לא נוסף.** המשפט כבר צרוב בתמונה של קליפ 5.

## מה מסומן רק לגרסת האישור

התגיות האדומות ״דיאלוג 1 עד 5״ ו ״קריינות הסיום״ יורדות בגרסה הסופית (`MARKERS=0`).

## מקורות סאונד

* מוזיקה: שלושה קטעים שהופקו ב ElevenLabs Music v2.5 דרך Higgsfield, ‏`audio/music`.
* אפקטים: Epidemic Sound דרך Higgsfield. הקבצים לא נשמרים בריפו. המזהים נמצאים ב `edit/prepare.py`.
* כדאי לוודא שתנאי הרישיון של Higgsfield מכסים פרסום מסחרי ממומן לפני שמעלים כמודעה בתשלום.

## בנייה מחדש

```bash
cd edit
pip install fonttools brotli numpy pillow
python3 prepare.py              # פונטים, קישור לקליפים, המרת מוזיקה. מדפיס אילו אפקטים חסרים
python3 audio.py                # מיקס ומאסטר ל 14 LUFS בערך
python3 video.py ../output/out.mp4
MARKERS=0 python3 video.py ../output/clean.mp4   # בלי תגיות הסימון
```

כל הזמנים נמצאים ב `edit/timeline.py`.
