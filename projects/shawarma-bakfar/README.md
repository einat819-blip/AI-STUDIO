1. מייבאים את `shawarma_bakfar_main_textless.mp4` ומשתיקים את הסאונד שלו.
2. מוסיפים את `stems/main_sfx_stem.wav` ואת `stems/main_music_stem.wav` מ-0:00, ומאזנים בינהם (בתמהיל המקורי המוזיקה נמוכה ב-3dB).
