# תבניות עבודה

תבניות למסירה. מלא רק את מה שהמשימה צריכה, ומחק שדות ריקים במקום למלא אותם בטקסט כללי.

## טבלת עבודה לתסריט ובימוי

| # | זמן | מה רואים ומה קורה | מצלמה | טקסט על המסך | קריינות | מוזיקה ואפקטים | חיבור לשוט הבא | חומר להפקה |
|---|---|---|---|---|---|---|---|---|
| 1 | 0:00 עד 0:02 | | | | | | | |
| 2 | 0:02 עד 0:05 | | | | | | | |

מתחת לטבלה:

- **סה״כ:** X שניות, מול אורך מבוקש של Y שניות.
- **סטטוס זמנים:** הצעה, עד שתיערך גרסה בפועל.
- **המסר האחד:** משפט אחד.

כללים לטבלה:

- כתוב טווחי זמן במילה ״עד״ ולא במקף.
- בעמודת הטקסט על המסך כתוב את הנוסח המדויק, כולל שבירת שורה אם היא חשובה.
- בעמודת המוזיקה והאפקטים כתוב מה שומעים ומתי, למשל ״שקט מלא עד הנקישה, ואז כניסת תוף״.
- בעמודת החיבור כתוב את סוג החיבור והסיבה, למשל ״חיתוך על תנועת היד״.

## כרטיס שוט להפקת AI

**שוט N: כותרת קצרה**

- **תמונת מקור או רפרנס:** מה מעלים לכלי, ומאיפה זה מגיע.
- **קומפוזיציה:** גודל שוט, מיקום הדמות במסגרת, יחס מסך.
- **פעולה מרכזית:** פעולה אחת ברורה.
- **מצלמה:** סטטית או תנועה אחת מוגדרת, וקצב התנועה.
- **תאורה ואווירה:** מקור האור, שעה ביום, טמפרטורת צבע.
- **פרטי רציפות:** זהות, גיל, בגדים, אביזרים, כיוון תנועה ותאורה מול השוט הקודם והבא.
- **לבדוק בתוצאה:** ידיים, פנים, השתקפויות, מגע, משקל גוף.
- **פרומפט:**

```
[Subject with fixed identity details], [one clear action], [setting].
Camera: [shot size], [single camera move or locked off], [lens feel].
Lighting: [source, time of day, mood].
Continuity: [wardrobe, props, screen direction].
```

- **חלופה פשוטה יותר אם הביצוע נכשל:** למשל שוט סטטי עם תנועה עדינה, זווית שמסתירה ידיים, או פיצול לשני שוטים.

התאם את מבנה הפרומפט לתיעוד של הכלי שנבחר. אל תוסיף פרמטרים או אפשרויות שלא אומתו.
