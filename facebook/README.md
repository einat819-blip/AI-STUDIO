## מה השתנה מול המקור

* חיתוך לכל שוט בנפרד, כדי שכל כיתוב והזמנה יישארו בתוך הפריים. חיתוך אחיד מהמרכז היה חותך את הבועות העליונות.
* שני השוטים הראשונים של ההזמנה (0 עד 1.5 ו 2.3 עד 3.3): הקטנה קלה עם מילוי רך בצדדים, כדי שגם הבועה וגם ההזמנה המלאה ייכנסו.
* ״כן, בבוקר!״: נשאר קרוב. התיבה של השעה יוצאת מהפריים לחצי שנייה, והיא כבר הופיעה בשוטים שלפני.
* האבא ויונתן: חיתוך נקי, בלי הקטנה.
* ״יש הזמנות שאי אפשר להתעלם מהן!״: הכרטיס נכנס כולו. משם יש התקרבות עדינה לכרטיס הסיום, שממלא עכשיו את כל רוחב המסך, כך שהטלפון גדול וקריא.
* סאונד, אורך וקצב לא השתנו.

## יצירה מחדש

```bash
ffmpeg -v error -i input_9x16.mp4 -f rawvideo -pix_fmt rgb24 - \
  | python3 tools/reframe45.py \
  | ffmpeg -y -f rawvideo -pix_fmt rgb24 -s 1080x1350 -r 24 -i - -i input_9x16.mp4 \
      -map 0:v -map 1:a -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -c:a copy \
      -movflags +faststart output_4x5.mp4
```

מפת החיתוך לכל שוט נמצאת בראש `tools/reframe45.py` ומתאימה רק לסרטון הזה.
