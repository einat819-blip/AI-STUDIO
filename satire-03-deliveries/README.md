# משלוחים לכל חלקי הארץ*
סרטון 3 בסדרת הסאטירה של AINATI STUDIOS · 1080×1920 · 30fps · H.264 + AAC

## מצב: טיוטה 1 (ללא קריינות)

`renders/draft_v1.mp4` היא טיוטת מבנה. היא **לא** גרסה לפרסום:

* קובץ הקריינות לא צורף. הכתוביות, המוזיקה וההנמכות מתוזמנים לפי **הערכה** של קצב הקריינות, ותווית ״טיוטה״ מופיעה בפינה.
* לשוטים 5 (המשך), 7 עד 13 אין עדיין חומר. במקומם יש שקופיות ״חסר חומר״ עם תיאור השוט והכתובית שלו.
* שוט 4 (שלוש אצבעות) חסר, ובמקומו משמש קליפ האגודל (שוטים 4 ו 5 ברצף אחד).

## מה צריך לגרסה הסופית

1. קובץ הקריינות (WAV או MP3) → `source/audio/narration.wav`
2. החומרים החסרים: שלוש אצבעות, המתנה בפתח הבית (התמונה עם החבילה), נקודת איסוף, משקפת ומפה, דגל ישראל, מפת אזורי חלוקה, המסע הבינלאומי, תיק הישרדות, המתולתלת במדים.
3. תזמון מילים אמיתי מתוך הקריינות → `edit/narration_words.json`. אפשר לייצר אותו כאן בתמלול עברי אוטומטי אם מאשרים לסביבה גישה ל huggingface.co, או לקבל קובץ SRT מהכלי שבו נוצרה הקריינות.

כשהחומרים מגיעים, מעדכנים את `edit/edit_v1.py` (מקורות ונקודות חיתוך) ומריצים רינדור. הכתוביות, המוזיקה והאפקטים זזים יחד עם המקטעים.

## מבנה

| תיקייה | תוכן |
|---|---|
| `source/clips` | חמשת הקליפים המקוריים, בשמות לפי תוכן |
| `source/images` | שקופית הסיום והלוגו המקורי |
| `edit/edit_v1.py` | רשימת העריכה: מקטעים, קריינות וכתוביות, מוזיקה, אפקטים, חשיפת שקופית הסיום |
| `edit/timeline_draft_v1.json` | ציר הזמן בפועל של הטיוטה |
| `assets/music` | שלוש יחידות מוזיקה מקוריות (ג'ינגל, הרפתקאות ואפי, פאנפרה) |
| `assets/sfx` | 19 אפקטים מקוריים |
| `assets/endcard` | שקופית הסיום עם הלוגו המקורי, רקע נקי ומסכות חשיפה |
| `assets/fonts` | Heebo ו Rubik (רישיון OFL, מותר לשימוש מסחרי) |
| `scripts` | סינתזת מוזיקה ואפקטים, בניית שקופית הסיום, מנוע הרינדור |
| `renders` | קובצי ה MP4 |

## הרצה

```bash
pip install numpy scipy soundfile opencv-python-headless pyloudnorm pillow
python3 scripts/make_sfx.py
python3 scripts/make_music.py
python3 scripts/make_endcard.py
python3 scripts/render.py edit/edit_v1.py renders/draft_v1.mp4
```

## זכויות

המוזיקה והאפקטים נוצרו כאן מאפס בסינתזה (ללא דגימות), כך שהם שייכים לסטודיו ואין רישיון צד שלישי לבדוק. הפונטים ברישיון SIL OFL.

## בדיקות שבוצעו בטיוטה 1

* עוצמה: ‎-14.0 LUFS Integrated, ‎-1.6 dBTP (נמדד על קובץ ה MP4 הסופי).
* וידאו: 1080×1920, 30fps, H.264 High, yuv420p. השמע הוא AAC בקצב 48kHz וב 320k.
* כל קליפ ממולא ל 9:16 בהגדלה אחידה בלבד, בלי מתיחה. הקליפ של נציג השירות בהלם (896×992) נחתך מהצדדים.
* הסאונד נבדק במדידות ובספקטרוגרמות בלבד. **לא בוצעה האזנה**.
