# משלוחים לכל חלקי הארץ*
סרטון 3 בסדרת הסאטירה של AINATI STUDIOS · 1080×1920 · 30fps · H.264 + AAC

## מצב: טיוטה 2 (ללא קריינות)

`renders/draft_v2.mp4` היא הטיוטה העדכנית (`renders/draft_v1.mp4` נשמרה להשוואה). היא **לא** גרסה לפרסום:

* קובץ הקריינות עדיין לא צורף. הכתוביות, המוזיקה וההנמכות מתוזמנים לפי **הערכה**, ותווית ״טיוטה״ מופיעה בפינה.
* שוטים 7 עד 13 משולבים בטיוטה עם החומר שהתקבל.
* עדיין חסרים: שוט 4 (שלוש אצבעות, ובינתיים מכוסה בקליפ האגודל) ושוט 5 (המשך): המתנה בפתח הבית, שמסומן בשקופית ״חסר חומר״.

### החלטות עריכה בטיוטה 2

* **שוט 8:** נבחר הקליפ שבו כתוב במפה ״אשכול״. בקליפ השני כתוב בטעות ״אשכיל״ (`S08_alt_UNUSED_map_typo_ashkil.mp4`), והוא לא בשימוש.
* **שוט 13:** השלט בקליפ חושף את הפאנץ' מהפריים הראשון. לכן ״משלוחים לכל חלקי הארץ!״ מושמע על חזרה לשוט הפתיחה, והקאט אליה נופל בדיוק על ״חוץ״. המוזיקה נעצרת באותו רגע.
* **כתוביות שלא מוצגות:** משפטים שכבר כתובים בתמונה (״משלוחים לכל חלקי הארץ!״, ״או נקודת איסוף!״, ״חוץ מהחלק שלכם.״, ״בהצלחה!״) לא מקבלים כתובית, כדי שלא תהיה כפילות.
* **הלוגו בפינה:** מוסתר רק בשני הקטעים של שוט 13 (3.6 שניות), כי שם הוא יושב על הכיתוב בשלט.
* **שוט 8:** הכתוביות יושבות נמוך יותר, כדי לא להסתיר את ״אשכול ✗״ במפה.

## מה צריך לגרסה הסופית

1. קובץ הקריינות (WAV או MP3) → `source/audio/narration.wav`
2. החומרים שעדיין חסרים: שוט 4 (שלוש אצבעות) ושוט 5 (המשך, המתנה בפתח הבית).
3. תזמון מילים אמיתי מתוך הקריינות → `edit/narration_words.json`. אפשר לייצר אותו כאן בתמלול עברי אוטומטי אם מאשרים לסביבה גישה ל huggingface.co, או לקבל קובץ SRT מהכלי שבו נוצרה הקריינות.

## מבנה

| תיקייה | תוכן |
|---|---|
| `source/clips` | הקליפים המקוריים, בשמות לפי מספר השוט והתוכן |
| `source/images` | שקופית הסיום והלוגו המקורי |
| `edit/edit_v2.py` | רשימת העריכה העדכנית: מקטעים, קריינות וכתוביות, מוזיקה, אפקטים, חשיפת שקופית הסיום (`edit_v1.py` היא הגרסה הקודמת) |
| `edit/timeline_draft_v2.json` | ציר הזמן בפועל של הטיוטה |
| `assets/music` | שלוש יחידות מוזיקה מקוריות (ג'ינגל, הרפתקאות ואפי, פאנפרה) |
| `assets/sfx` | 20 אפקטים מקוריים |
| `assets/endcard` | שקופית הסיום עם הלוגו המקורי, רקע נקי ומסכות חשיפה |
| `assets/fonts` | Heebo ו Rubik (רישיון OFL, מותר לשימוש מסחרי) |
| `scripts` | סינתזת מוזיקה ואפקטים, בניית שקופית הסיום, מנוע הרינדור |
| `renders` | קובצי ה MP4 |

## הרצה

```bash
pip install numpy scipy soundfile opencv-python-headless pyloudnorm pillow
python3 scripts/make_sfx.py
python3 scripts/make_music.py
python3 scripts/make_endcard.py
python3 scripts/render.py edit/edit_v2.py renders/draft_v2.mp4
```

## זכויות

המוזיקה והאפקטים נוצרו כאן מאפס בסינתזה (ללא דגימות), כך שהם שייכים לסטודיו ואין רישיון צד שלישי לבדוק. הפונטים ברישיון SIL OFL.

## בדיקות שבוצעו בטיוטה 2

* עוצמה: ‎-14.0 LUFS Integrated, ‎-1.8 dBTP (נמדד על קובץ ה MP4 הסופי).
* וידאו: 1080×1920, 30fps, H.264 High, yuv420p. השמע הוא AAC בקצב 48kHz וב 320k.
* כל קליפ ממולא ל 9:16 בהגדלה אחידה בלבד, בלי מתיחה. הקליפ של נציג השירות בהלם (896×992) נחתך מהצדדים.
* הסאונד נבדק במדידות ובספקטרוגרמות בלבד. **לא בוצעה האזנה**.
